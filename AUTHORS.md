## Creator and Lead Developer

**Yoseph Abebe**  
Based in Addis Ababa, Ethiopia  
GitHub: [@1yos](https://github.com/1yos)

Yoseph created AetherDSP with a vision to build a production-grade audio engine that celebrates musical traditions from around the world — particularly Ethiopian, Arabic, Indian, and Javanese music. The project combines hard real-time DSP engineering with deep respect for non-Western musical systems.

---

## Project History

AetherDSP began as a personal exploration of real-time audio processing in Rust and evolved into a comprehensive music production platform. The project emphasizes:

- **Technical Excellence**: Lock-free algorithms, zero-allocation RT guarantees, and SIMD optimization
- **Cultural Authenticity**: Proper implementation of microtonal tuning systems with musicological research
- **Open Source**: MIT licensed, with all code and documentation freely available

## Contributing

Contributions are welcome! See [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines.

- Musicological sources (academic papers, recordings, or expert consultation)
- Clear documentation of interval ratios or cent deviations
- Context about regional variations if applicable
