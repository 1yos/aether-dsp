# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.2] - 2026-05-12

### Added
- Comprehensive CHANGELOG.md with full version history
- Working examples demonstrating real-world usage
- Improved documentation for better discoverability


## [0.1.1] - 2026-05-12

### Added

- Comprehensive inline documentation for manifest format
- Validation examples

### Fixed

- JSON schema validation for nested parameter definitions

## [0.1.0] - 2026-04-01

### Added

- Initial release of node package manifest format
- NodeManifest struct for package metadata
- Parameter definition schema
- Input/output port specification
- Category and tag system for node discovery
- JSON serialization/deserialization
- Manifest validation

### Features

- Semantic versioning support
- Author and license metadata
- Parameter constraints (min/max/default)
- Port naming and type information
